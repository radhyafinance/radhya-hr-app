# Radhya HR — Android app

Download the latest version of the Radhya HR app for Android:

**https://github.com/radhyafinance/radhya-hr-app/releases/latest/download/radhya-hr.apk**

This link always gives the newest version.

## Installing

1. Open the link above on your Android phone.
2. When the download finishes, tap the file to install.
3. If the phone asks, allow installing apps from this source (Chrome / Files).
4. Updating? Install over the old app — you do not need to uninstall it or log in again.

Problems installing? Contact HR.

This repository holds app downloads only.
